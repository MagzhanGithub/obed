# Заказ обедов — Vercel + Supabase

Сайт для заказа обедов: меню с фото, корзина, оплата через Kaspi, заказ в WhatsApp, админка (канбан заказов, аналитика). Данные хранятся в Supabase, вход для админа по логину и паролю.

## Структура
- `public/index.html` — сайт (покупатели и админка)
- `api/[action].js` — серверная часть (Vercel Functions)
- `schema.sql` — таблица для базы
- `package.json`

## Шаг 1. База данных (Supabase)
1. Зарегистрируйтесь на supabase.com и создайте проект (регион выберите ближайший).
2. Откройте **SQL Editor**, вставьте содержимое `schema.sql`, нажмите **Run**.
3. Откройте **Project Settings → API** и скопируйте:
   - **Project URL** → это `SUPABASE_URL`
   - **service_role** (или Secret key) → это `SUPABASE_SERVICE_KEY`.
   Этот ключ секретный: не вставляйте его в код и не публикуйте.

## Шаг 2. Код на GitHub
1. Создайте на github.com пустой репозиторий (лучше приватный).
2. Загрузите в него все файлы этой папки: **Add file → Upload files**. Папки `api` и `public` должны остаться папками.

## Шаг 3. Vercel
1. На vercel.com нажмите **Add New → Project** и выберите ваш репозиторий.
2. **Framework Preset**: Other. Build Command и Output Directory оставьте пустыми.
3. Откройте **Environment Variables** и добавьте:

| Имя | Значение |
|---|---|
| `SUPABASE_URL` | Project URL из Supabase |
| `SUPABASE_SERVICE_KEY` | service_role ключ |
| `ADMIN_USER` | `maga` |
| `ADMIN_PASSWORD` | `9598` |
| `AUTH_SECRET` | любая длинная случайная строка (20+ символов) |

4. Нажмите **Deploy**. Через минуту сайт будет доступен по адресу вида `название.vercel.app`.
5. Если позже меняете переменные, нажмите **Redeploy**.

## Шаг 4. Первая настройка
1. Откройте сайт, вкладка **Админ**, войдите (maga / 9598).
2. В «Настройках» введите номер Kaspi, номер WhatsApp (с кодом страны, например `77071234567`) и список департаментов через запятую.
3. Добавьте блюда на сегодня и фото (кнопка 📷, фото автоматически обрезается до квадрата).
4. Отправьте ссылку сотрудникам. Вход им не нужен.

## Свой домен
Vercel → Project → **Settings → Domains** → добавьте домен и пропишите DNS-записи, которые покажет Vercel.

## Безопасность
- Пароль из четырёх цифр слабый. После запуска лучше заменить `ADMIN_PASSWORD` на более длинный. В коде пароль не хранится, только в переменных Vercel.
- После 8 неверных попыток вход блокируется на 10 минут (защита простая и работает в пределах одного экземпляра сервера).
- Цены считает сервер: покупатель не может подменить сумму заказа.
- Вход админа действует 12 часов.

## Как это работает и ограничения
- Страница обновляется сама каждые 15 секунд.
- Остаток блюд уменьшается при переносе заказа в «Оплачен». Он не резервируется при создании заказа.
- Аналитика считается по оплаченным заказам, разбивка «до/после 18:00» по времени оплаты. Итог в WhatsApp автоматически не отправляется.
- Дата и «сегодня» считаются по времени Казахстана (UTC+5).
- Проверять оплату по чеку в WhatsApp нужно вручную.

## Локальный запуск (по желанию)
```
npm i -g vercel
npm install
vercel dev
```
Переменные окружения для локального запуска задаются командой `vercel env pull` либо файлом `.env`.
